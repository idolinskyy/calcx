# calx

Консольний калькулятор на **C++23**: джерело → лексер → парсер (AST) →
байткод → стекова ВМ. Бінарник — `calc`. Ліцензія: **GPL-3.0-or-later**
(`LICENSE`, `COPYRIGHT`; сторонні залежності — у `NOTICE`).

## Швидкий старт

### Збірка

Потрібні CMake ≥ 3.28 і компілятор з підтримкою C++23 (g++ / clang++).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

Результат:

| Файл               | Призначення                                 |
| ------------------ | ------------------------------------------- |
| `build/calc`       | Виконуваний калькулятор                     |
| `build/calc_tests` | Набір тестів                                |
| `build/libcalc.a`  | Бібліотека (лексер, парсер, компілятор, ВМ) |

### Запуск

Інтерактивно (без аргументів у терміналі) — REPL (**replxx**: історія `↑`/`↓`,
підсвітка синтаксису, Tab-доповнення; файл `~/.calc_history`). Рядки
накопичуються в сесію, тож `let` / `fun` лишаються між введеннями:

```bash
./build/calc
```

```
calc> let a = 12 * (3 + 2)
calc> print("sum = {}", a + -1.23)
sum = 58.77
calc> :quit
```

Команди REPL: `:help`, `:clear` (скинути сесію), `:quit`. Примусово:
`./build/calc -i`.

З файлу:

```bash
./build/calc program.calc
```

Зі стандартного вводу (пайп / heredoc — не REPL):

```bash
./build/calc <<'EOF'
let a = 12 * (3 + 2); let compl = 2 + 2i, neg = -1.23;
let sum = a + neg;
print("sum = {}", sum);
print(a * neg);
EOF
```

Вивід:

```
sum = 58.77
-73.8
```

Дамп байткоду (лише компіляція, без виконання):

```bash
./build/calc -S program.calc
```

Якщо потрібні ще **тип і фінальне значення** змінних — окремий явний ключ (тихий прогін ВМ, `print` ховається):

```bash
./build/calc --dump-run program.calc
```

Службові слоти компілятора для `for-in` (`__it`, `__i`, `__e`) у секції «змінні» за
замовчуванням сховані; щоб побачити їх у дампі:

```bash
./build/calc -S --dump-temps program.calc
```

Довідка: `./build/calc --help`

Код виходу: `0` — успіх, `1` — помилка (діагностика йде в stderr).

### Тести

```bash
LSAN_OPTIONS=detect_leaks=0 ./build/calc_tests
# або
ctest --test-dir build --output-on-failure
```

## Мова

Підтримується: типи (Boolean, Integer, Rational, Real, Complex), `let` і
присвоєння, `print` (із форматом), `if` / `else`, `while` / `for` /
`for-in`, `break` / `continue`, `fun` / `return`, масиви, записи, builtins і
іменовані константи, інтерактивний REPL.

Оператори `let`, присвоєння, `print`, `return`, `break`, `continue` і
вираз-оператор (напр. `push(a, 1);`) закінчуються `;`. У REPL крапку з комою
в кінці рядка можна опустити.

### Короткі приклади

```
let q = 3/4;                 // Rational
let z = 1 + 2i;              // Complex
print("q={} |z|≈{:.3f}", q, abs(z));

if (q < 1) { print("ok"); }

fun fact(n) {
  if (n <= 1) return 1;
  return n * fact(n - 1);
}
print(fact(5));

let a = [10, 20];
push(a, 30);
for (i, v in a) { print("{}:{}", i, v); }

let p = { x: 1, y: 2 };
p.z = p.x + p.y;
for (k, v in p) { print("{}={}", k, v); }
```

### Змінні

```
let name = вираз;
let a = 1, b = a * 2, c = -3.5;
```

- Ініціалізатор **обовʼязковий** (`let a;` — помилка).
- Повторне імʼя в тій самій області — помилка.
- Імʼя видиме лише **після** свого ініціалізатора: `let a = 2, b = a * 3` — ок; `let a = a + 1` — помилка.
- Ідентифікатори: `[A-Za-z_][A-Za-z0-9_]*`.

### Присвоєння

```
name = вираз;
```

- Змінна має бути вже оголошена через `let` (інакше — помилка).
- Потрібна для лічильників у циклах.

### Вивід

```
print(вираз);
print("формат", вираз, ...);
```

- Без формату друкується значення і новий рядок.
- З форматом — синтаксис як у **`std::print` / `std::format`**:
  - `{}`, `{0}`, `{1}` (автоматична або ручна індексація; змішувати не можна);
  - специфікатори: `{:.2f}`, `{:d}`, `{:x}`, `{:>8}`, …
  - `{{` / `}}` — літеральні дужки.
- Integer / Real / Boolean форматуються через `std::format`; Rational без spec — як `1/2`, зі numeric spec — як Real; Complex — лише `{}` (власний друк).
- Кількість аргументів звіряється на етапі компіляції.
- У рядку дозволені escape: `\n` `\t` `\r` `\\` `\"`.

```
print("pi ≈ {:.2f}", 22 / 7);
print("{1} after {0}", 10, 20);
print("hex={:x}", 255);
```

### Розгалуження

```
if (умова) оператор
if (умова) оператор else оператор
if (умова) { ... } else if (умова) { ... } else { ... }
```

- Умова має бути **Boolean** (`true`/`false` або результат порівняння / `and`/`or`/`not`). Інакше — помилка виконання.
- Гілка — будь-який оператор: `let`, `print`, вкладений `if`, або блок `{ ... }`.
- `else` чіпляється до **найближчого** `if` (як у C/C++).
- Блок `{ ... }` створює **нову область видимості** для `let`: внутрішнє імʼя може затінювати зовнішнє; після `}` внутрішні імена недоступні.
- Ланцюжок `else if` — це `else` з вкладеним `if`.

```
let x = 0;
if (x < 0) {
  print("neg");
} else if (x == 0) {
  print("zero");
} else {
  print("pos");
}
```

### Цикли

```
while (умова) оператор

for (init; умова; step) оператор
```

- Умова — Boolean (як у `if`). Порожня умова в `for` означає `true`.
- `init`: порожньо, `let ...;`, або присвоєння; `step`: порожньо або присвоєння без `;` перед `)`.
- `let` у `init` видимий у умові, `step` і тілі; після циклу — ні.
- `for` — синтаксичний цукор: область `{ init; while (cond) { body; step; } }` (з коректним `continue` → на `step`).
- `break;` / `continue;` — лише всередині циклу; діють на **найближчий** цикл.

```
let i = 0;
while (i < 3) {
  print(i);
  i = i + 1;
}

for (let n = 0; n < 3; n = n + 1) {
  if (n == 1) continue;
  print(n);
}
```

### for-in

```
for (x in arr) { ... }       // елементи масиву або ключі запису
for (i, x in arr) { ... }    // індекс і елемент (масив)
for (k, v in obj) { ... }    // ключ і значення (запис)
```

- Ітерація по запису в режимі одного імені дає ключі (тип String у ВМ).
- Ключ можна використати як індекс: `obj[k]` (змінна, не рядковий літерал).

### Функції

```
fun name(a, b) {
  return a + b;
}
print(name(1, 2));
```

- Оголошення `fun` — **лише на верхньому рівні** програми (не всередині блоків).
- Параметри — локальні слоти кадру; тіло має власні `let` (без замикань на зовнішні змінні).
- `return вираз;` або `return;` (тоді повертається `0`). Якщо `return` немає — неявно `0`.
- Взаємна рекурсія дозволена (усі `fun` реєструються перед компіляцією тіл).
- Невірна кількість аргументів — помилка компіляції (`ArityMismatch`).

### Вбудовані функції

| Група         | Імена                                    | Аргументи                              |
| ------------- | ---------------------------------------- | -------------------------------------- |
| Тригонометрія | `sin` `cos` `tan` `asin` `acos` `atan`   | 1 (Real/Complex)                       |
|               | `atan2`                                  | 2: `(y, x)` лише дійсні                |
| Гіперболічні  | `sinh` `cosh` `tanh`                     | 1                                      |
| Степінь / log | `sqrt` `exp` `ln` (`log`) `log10` `log2` | 1                                      |
|               | `pow` `hypot`                            | 2                                      |
| Модуль / знак | `abs` `sign`                             | 1; `sign` — лише дійсні → `-1`/`0`/`1` |
| Комплексні    | `re` `im` `arg` `conj`                   | 1                                      |
| Округлення    | `floor` `ceil` `round` `trunc`           | 1, лише дійсні                         |
| Порівняння    | `min` `max`                              | 2, лише дійсні                         |
| Кути          | `deg` `rad`                              | 1: радіани↔градуси                     |

- `sqrt` відʼємного дійсного → Complex; `abs` для Integer/Rational зберігає тип.
- Alias: `log` = `ln` (натуральний логарифм).
- Не можна оголосити `fun` з іменем builtin або вбудованої константи.

```
print(abs(-3));
print(hypot(3, 4));
print(floor(3.7));
print("re={} im={}", re(3 + 4i), im(3 + 4i));
```

### Вбудовані константи

Імена без `()`; підставляються як Real (або Complex для `i`), якщо немає локальної змінної з тим самим імʼям (`let` може затінити).

| Група      | Імена                                             | Зміст (SI, де доречно)                                         |
| ---------- | ------------------------------------------------- | -------------------------------------------------------------- |
| Математика | `pi` `e` `tau` `phi` `sqrt2` `sqrt3` `ln2` `ln10` | `std::numbers` / похідні                                       |
|            | `i`                                               | уявна одиниця `0 + 1i`                                         |
| Фізика     | `c` `G` `h` `hbar` `qe` `me` `mp` `mn` `u`        | світло, гравітація, Планк, заряд, маси, а.о.м.                 |
|            | `eps0` `mu0` `alpha` `sigma` `g` `atm` `Ry` `a0`  | вакуум, тонка структура, Стефан–Больцман, g, атм, Рідберг, Бор |
| Хімія      | `NA` `kB` (`k`) `R` `F` `Vm` `celsius0`           | Авогадро, Больцман, газова, Фарадей, молярний обʼєм, 0 °C у K  |

```
print("{:.4f}", pi);
print(c);
print(1 + i);   // 1 + 1i
print(NA * qe == F);  // true (в межах Real)
```

Елементарний заряд — `qe` (не `e`: `e` = число Ейлера).

### Масиви

```
let a = [1, 2, 3];
let empty = [];          // порожній масив — ок
print(a[0]);
a[1] = 9;
push(a, 4);
print(pop(a));
print(len(a));

for (x in a) { print(x); }
for (i, x in a) { print("{}:{}", i, x); }
```

- Літерал `[...]` (зокрема `[]`), індексація `a[i]` (Integer, з 0).
- **Семантика за посиланням:** `let b = a` ділить дані; мутації через `b` видно в `a`.
- Builtins: `len(a)`, `push(a, x)` (повертає той самий масив), `pop(a)`.
- `for (x in arr)` — елементи; `for (i, x in arr)` — індекс і елемент.

### Записи (обʼєкти)

```
let p = { x: 1, y: 2 };
let empty = {};          // порожній запис — ок
print(p.x);
p.z = 3;          // додає поле
print(len(p));

for (k in p) { print(k); }           // ключі (рядки)
for (k, v in p) { print("{}={}", k, v); }
```

- Літерал `{ name: expr, ... }` у **виразі** (у операторі `{ ... }` лишається блок); `{}` — порожній запис.
- Доступ: `p.field` або `p[key]`, де `key` — значення String (наприклад з `for-in`).
  Рядковий літерал `"…"` у виразах **заборонений** (рядки лише як формат `print`).
- Присвоєння оновлює або створює поле; семантика **за посиланням**, як у масивів.
- `len(p)` — кількість полів. Методів з `this` немає (звичайні `fun`).

### Вирази

| Група      | Оператори                  | Асоціативність         |
| ---------- | -------------------------- | ---------------------- |
| Логіка     | `or`, `and`, унарний `not` | ліва (`not` — унарний) |
| Рівність   | `==` `!=`                  | ліва                   |
| Порівняння | `<` `<=` `>` `>=`          | ліва                   |
| Додавання  | `+` `-`                    | ліва                   |
| Множення   | `*` `/` `%`                | ліва                   |
| Унарні     | `+` `-` `not`              |                        |
| Степінь    | `**`                       | **права**              |

Пріоритет зверху вниз зростає (степінь найсильніший серед бінарних). Дужки `(...)` змінюють порядок.

Коментар: `//` до кінця рядка.

Логічні літерали: `true`, `false` (тип Boolean).  
`and` / `or` / `not` працюють **лише** з Boolean (без неявного `1`→true). Обидва операнди `and`/`or` обчислюються завжди (без short-circuit; опкоди `Jump` / `JumpIfFalse` уже є для `if`).

### Літерали

| Запис                | Тип                                 |
| -------------------- | ----------------------------------- |
| `true`, `false`      | Boolean                             |
| `12`                 | Integer (`std::int64_t`)            |
| `1/2`, `3/4`         | Rational (без пробілів навколо `/`) |
| `2.0`, `.5`, `2e1`   | Real (`long double`)                |
| `2i`, `2.5i`, `2e1i` | Complex (чисто уявне)               |
| `2 + 2i`             | Complex                             |

Різниця: **`1/2`** — літерал-дріб; **`1 / 2`** — ділення (пробіли навколо `/`).
Окреме імʼя `i` у `let` затінює константу уявної одиниці. Рядки — лише аргумент
формату в `print`, не значення змінних.

## Типи і арифметика

Тип виводиться з виразу автоматично.

| Операція                  | Правило                                                                |
| ------------------------- | ---------------------------------------------------------------------- |
| `+` `-` `*` і унарний `-` | Integer лишається Integer, поки не зʼявиться Rational / Real / Complex |
| Integer + Rational        | Rational (скорочений; якщо знаменник 1 → Integer)                      |
| Rational + Real           | Real                                                                   |
| будь-що + Complex         | Complex                                                                |
| `1 / 2` (пробіли)         | ділення → Real (`2.5`) або Complex                                     |
| `1/2` (літерал)           | Rational; арифметика дробів лишається точною                           |
| `%`                       | Integer→Integer; інакше Real; Complex/Boolean — помилка                |
| `**`                      | степінь (цілий показник може дати Integer/Rational)                    |
| `<` `<=` `>` `>=`         | числа (не Complex) → Boolean                                           |
| `==` `!=`                 | числа або Boolean↔Boolean                                              |
| `and` `or` `not`          | лише Boolean → Boolean                                                 |

Результат Real **не звужується** назад до Integer (`2.0 * 3.0` — Real).  
Rational зі знаменником 1 після скорочення стає Integer (`1/2 + 1/2` → `1`).

Помилки виконання:

- цілочисельне переповнення;
- ділення на нуль (включно з `0+0i`);
- нескінченний / NaN результат;
- недопустима операція для типу (`true + 1`, `1 and true`, `2i < 3i`).

### Друк значень

- Boolean: `true`, `false`
- Integer: `60`, `-12`
- Rational: `1/2`, `-3/4`
- Real: до 15 значущих цифр; ціле за значенням — з `.0` (`2.0`)
- Complex: `2 + 2i`, `2 - 3.5i`, `2i`, `-2i`; нульова уявна частина — `2 + 0i`

## Архітектура

```
джерело → лексер → парсер (AST) → компілятор (байткод) → ВМ → вивід
```

| Компонент             | Файли                                                               |
| --------------------- | ------------------------------------------------------------------- |
| Значення / арифметика | `include/calc/value.hpp`, `src/value.cpp`                           |
| Лексер                | `include/calc/lexer.hpp`, `src/lexer.cpp`                           |
| Парсер / AST          | `include/calc/parser.hpp`, `include/calc/ast.hpp`, `src/parser.cpp` |
| Байткод               | `include/calc/chunk.hpp`                                            |
| Компілятор            | `include/calc/compiler.hpp`, `src/compiler.cpp`                     |
| ВМ                    | `include/calc/vm.hpp`, `src/vm.cpp`                                 |
| Фасад                 | `include/calc/engine.hpp`, `src/engine.cpp`                         |

Фасад для вбудовування:

```cpp
#include "calc/engine.hpp"
#include <sstream>

std::ostringstream out;
auto r = calc::run("print(1 + 2);", out);
// або лише компіляція: calc::compile_source(source)
```
